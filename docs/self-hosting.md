# Self-Hosting Guide

The self-hosting Compose files live at the repository root:
[`../docker-compose.yml`](../docker-compose.yml) pulls published images, while
[`../docker-compose.self-hosting.yml`](../docker-compose.self-hosting.yml)
builds the frontend and backend locally. Start with the
[setup guide](../self-hosting/docs/setup-guide.md).
